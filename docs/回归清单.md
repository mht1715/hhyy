# 流式与多 Agent 手工回归清单（M2-14）

> 用途：每次改动 `chat` 链路（后端编排 / SSE 协议 / 前端 Chat 组件）后，按这张表过一遍。
> **状态列说明**：`API 已验证` = 用脚本打过真实接口并有断言；`待人工` = 必须开浏览器点，本次未执行。

准备：

```powershell
.\script\dev.ps1 up            # 依赖
.\script\dev.ps1 init          # 迁移到 0003
.\script\dev.ps1 agents        # 4 个 Agent
.\script\dev.ps1 backend       # 8000
.\script\dev.ps1 frontend      # 5173
```

账号：`patient/123456`、`support/123456`、`admin/123456`；游客不登录。

| # | 用例 | 步骤 | 期望 | 状态 |
| --- | --- | --- | --- | --- |
| 1 | 单 Agent 流式 + 引用 + 免责声明 | 药品详情页问「哺乳期能吃吗」 | 文字逐字出现；角标 `[1]` 可点开抽屉看到说明书【禁忌】原文；末尾带免责声明 | 待人工（API 已验证：`citations=1`、`guardrail.flags` 含 `disclaimer_injected`） |
| 2 | `@` 单个 Agent | 输入框打 `@` 选「订单售后」，问「这单能退吗」 | 候选面板按权限过滤（游客看不到订单售后）；回答只有订单维度内容 | 待人工（API 已验证：`route.mode=mention`、`contributors=[order_after_sale]`） |
| 3 | `@` 两个 Agent 并行 | `@AI药师 @订单售后 哺乳期能吃花红片吗？我这单能退吗？` | 两段带来源标签的结论；总耗时 ≈ 慢的那一路（不是两段相加） | 待人工（API 已验证：两路各 1.8s/2.9s，整体 5.0s；`contributors` 两个） |
| 4 | 停止生成 | 回答流式中点「停止」 | 立刻停；**之后不再追加任何 token**；已生成内容保留 | 待人工 |
| 5 | 重试 | 上一条回答报错或点重试 | 复用同一消息位重新生成，不新增一条重复的用户消息 | 待人工 |
| 6 | 幂等 | 连点两次发送（同一 `client_message_id`） | 第二次直接重放，`done.replayed=true`，不重复扣费 | 待人工（API 已验证：第二次 `replayed=true`） |
| 7 | 权限与降级 | 游客打开 `/agents`；游客访问 `/agents/order_after_sale` | 广场只显示「企业介绍」；直接访问被拦并提示 | 待人工（API 已验证：`GET /api/agents` 游客仅 1 个、`/api/chat/stream` 返回 403） |

## 断言依据（API 层实测，2026-11-18）

```text
GET  /api/agents          游客  → ['company_intro']
                          患者  → ['company_intro','drug_consult','order_after_sale']
                          管理员→ + ['customer_service']
POST /api/chat/stream     双 @  → route(mode=mention) → agent×2 start
                                 → tool(kb_search/policy_search/order_lookup)
                                 → retrieval×2 → citation×10 → delta → done
                                 latency 5038ms，contributors 两个
                          企业问题 → supervisor 路由 company_intro（conf 0.98）
                          退货问题 → supervisor 路由 order_after_sale（conf 0.95）
                          「嗯」   → clarify（conf 0.05），列出 3 个可用助手
                          伪造 mention → error(FORBIDDEN_AGENT)
                          同一 client_message_id → 第二次 done.replayed=true
                          第 3 次/分钟（限流设 2）→ HTTP 429
```
