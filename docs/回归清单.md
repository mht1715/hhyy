                          「我要投诉…」→ meta → route → memory → handoff(ticket,queued)
                          → agent → … → done(status=handoff_pending)
POST /api/handoff         重复请求 → 同一 ticket_id、queue_position=1
GET  /api/support/tickets 1 单：user_label=patient、wait_seconds 9、summary 六字段齐全
POST .../accept           200 assigned；再调 → 409「工单状态不允许该操作：assigned → assigned」
POST /api/support/ws-ticket → ws_ticket；WS 首帧 auth → ready(role=user/support)
WS   双向                 坐席→患者 human_agent 消息；患者→坐席 user 消息
POST /api/chat/stream     接管后 → 只有 meta + done(silenced=true, status=human_active)
POST .../resolve          200 resolved；GET /api/conversations/{id} status=closed，含 human_agent
POST /api/handoff/offline 200 offline
GET/PATCH/DELETE /api/me/memory  列表 / 关闭 / 删除（删除同时清 Milvus 向量）
checkpoints               24 行；每个会话 1 行（durability=exit），新进程可读
